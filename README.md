# Tech Challenge — Fase 4 | FIAP

## Análise de Produtos e Avaliações da Amazon

Projeto desenvolvido para a Pós-Tech em Data Analytics da FIAP.

### Objetivo
Analisar o portfólio de produtos da Amazon, explorando categorias,
preços, descontos, avaliações e comentários dos consumidores.

### Tecnologias utilizadas
- Power BI
- Power Query
- DAX
- GitHub

### Estrutura do projeto
- dashboard: arquivo Power BI (.pbix)
- dados: informações sobre a base utilizada
- documentacao: metodologia e respostas às questões de negócio
- imagens: capturas dos dashboards
- video: apresentação do projeto

### Principais resultados
- 1.351 produtos únicos analisados
- Avaliação média de 4,09 estrelas
- Desconto médio de 46,68%
- 41 produtos com avaliações inferiores a 3,5 estrelas

### Metodologia
Foi adotada uma abordagem híbrida para o tratamento das duplicidades,
consolidando os produtos para os indicadores quantitativos e preservando
os registros originais para análises de avaliações e comentários.
